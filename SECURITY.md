# Security Policy

## Supported Versions
This repository contains documentation templates, so all active content on `main` is considered supported.

## Reporting a Vulnerability
If you identify a security issue in repository content (for example, unsafe security guidance):

1. Do not open a public issue with sensitive details.
2. Contact the maintainer privately with:
   - A clear description of the issue
   - Impact assessment
   - Suggested remediation (if available)
3. Allow reasonable time for review and correction before public disclosure.

## Scope
- In scope: Insecure or misleading security recommendations in templates/examples.
- Out of scope: Vulnerabilities in third-party tools not maintained in this repository.
